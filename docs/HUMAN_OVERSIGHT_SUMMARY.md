# Human Oversight Summary / 人手監督摘要

All 72 outputs received documented human review before the findings were finalised.

全部 72 個輸出均在研究結論定稿前完成人手覆核及留有紀錄。

## Operating model / 運作模式

- **Human-in-the-loop:** human judgment was required before flagged outputs were accepted.
- **Human-in-command:** the project owner retained authority to reject outputs, stop the study and approve disclosure.
- **Risk-tiered review:** 36 high-priority outputs were adjudicated individually; 36 routine outputs were reviewed as a defined batch with four material exceptions retained separately.
- **Meaningful review:** the reviewer received the question, model output, intended boundary and supporting-source context—not only a numeric score.
- **Traceability:** each request, decision, rationale and implementation was retained in the private canonical record.

- **Human-in-the-loop（人在迴路）：** flagged 輸出獲接納前必須有人手判斷。
- **Human-in-command（人類主導）：** 項目負責人保留否決輸出、停止研究及批准披露的權力。
- **分級風險覆核：** 36 個高優先輸出逐項裁定；36 個一般輸出按已定義批次覆核，四個重大例外則獨立保留。
- **有實質作用的覆核：** reviewer 會睇問題、模型輸出、預定界線及來源，而唔係只睇數字分數。
- **可追溯性：** 每次要求、決定、理由及落實方式均保存於 private canonical record。

Exact reviewer identity, verbatim responses and private notes are deliberately excluded from this public summary under data-minimisation principles.

按資料最少化原則，本公開摘要刻意排除 reviewer 身份、回覆原句及私有備註。
