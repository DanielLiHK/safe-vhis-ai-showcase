# Publication Scope / 發布範圍

This public repository is a sanitised, allow-listed snapshot generated from a private canonical research repository. It is not an independently developed fork.

本 public repository 係由 private canonical research repository 按 allow-list 產生的經清理 snapshot，並非獨立開發的 fork。

## Included / 已公開

- Source code, unit tests and read-only CI.
- Synthetic bilingual test cases and paraphrased public-source notes.
- Aggregate results, selected failure cases and anonymised human-oversight evidence.
- Methodology, Responsible AI controls, limitations and security guidance.

- 程式碼、單元測試及只讀 CI。
- 中英雙語 synthetic 個案及改寫後公開來源筆記。
- 匯總結果、精選失敗案例及匿名人手監督證據。
- 方法、Responsible AI 控制、限制及安全指引。

## Excluded / 未公開

- Complete raw model outputs and row-level grading.
- Verbatim human responses, reviewer identity and private notes.
- Private workflow-run and artifact identifiers.
- Credentials, workspace identifiers and any personal data.

- 模型完整原始輸出及逐行評分。
- 人手回覆原句、reviewer 身份及私有備註。
- Private workflow run 及 artifact identifiers。
- 憑證、workspace identifier 及任何個人資料。

Public results are evidence about one frozen synthetic benchmark only. They are not a certification, regulatory approval or guarantee of safety.

公開結果只係一次鎖定 synthetic benchmark 的證據，並非認證、監管批准或安全保證。
